# M03 website identity and audit method

M03 uses the audited identity rules in `CODEX_SIGNALPOST_FINAL_IMPLEMENTATION_PLAN_AUDITED.md` §8.2–8.3. Registry and keyless URLs remain candidates. A candidate is promoted only after the page evidence yields a subject-scoped exact organisation number and compatible legal name, or a permitted exact legal-name/address proof. Keyless candidates also require a registered-role match. Name-only, brand-only, group-homepage-only, conflicting structured-company identity, customer/partner-context identifiers, and social URLs as website domains do not publish an owned-domain claim.

The input to `scripts/summarize_m03_audit.py` is the canonical JSONL run output. The final live audit used batch id `m03-final-website-audit-v4`, the 200-row M00 cohort (`m00-company-sample-200.jsonl`, SHA-256 `cee97e17af7e8b2d9dc9f5ee60548b9e186a11a2e485469446219ea10a1e38ed`), and candidate source URL `https://builderr.ai/signalpost-company-universe-2025.jsonl.gz`. Its archive-specific rights remain unresolved; the frozen URL was used only as candidate discovery input, and no frozen-source claim was promoted. Accepted claims cite the fetched page and deterministic proof. The report retains candidate source and decision, final URL/domain, proof method and deterministic proof identifiers, claim family counts, gateway request and page counts, and runtime summaries. Raw page bodies are not retained. The accepted-domain CSV is an audit sheet: every row contains the exact organisation number and the proof record/evidence IDs.

The M03 gate has two checks. The adversarial fixture suite must publish zero claims for wrong-company, unrelated-ID, shared-group-homepage, and cross-domain redirect cases. The live opportunity audit must retain an evidence-backed proof record for every accepted domain and report its exact sample and denominators. It does not produce a population precision estimate; the 200-row M00 sample is a stratified opportunity cohort, not a human-labelled release audit. Search stays disabled, so the M04 300-candidate search-provider promotion gate is not in scope.

The checked-in M00 cohort contains 200 companies. Expanding the live run to at least 1,000 requires a fresh, rights-reviewed frozen source cohort; M03 does not infer those labels from live discovery outcomes or describe the 200 sample as calibrated precision.
