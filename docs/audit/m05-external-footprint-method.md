# M05 jobs and company activity benchmark

The live release audit used the same ordered 200-company opportunity cohort as M04: [`m00-company-sample-200.jsonl`](m00-company-sample-200.jsonl), SHA-256 `cee97e17af7e8b2d9dc9f5ee60548b9e186a11a2e485469446219ea10a1e38ed`. Frozen rows were used only as exact target identity/candidate anchors, consistent with the M04 limitation; the report does not represent that archive's licence as resolved. Search stayed disabled. The run used the exact-site M03 path, live company-owned website requests through `NetworkGateway`, the bounded keyless fallback and evidence cutoff `2026-10-03T23:59:00+05:30`.

`m05-external-footprint-benchmark.json` records the canonical output audit, gateway request counts and outcomes, runtime, state distribution, job/activity atomic claim counts and provenance checks, M04 accepted-domain delta, and observed error interval. One envelope was emitted for each of 200 inputs. The run made 96 physical and 152 logical gateway requests, completed in 68.844 seconds, made no paid requests, and stayed below the 3,400 request budget. Outcomes included 80 `ROBOTS_UNREACHABLE` site failures; they remain failed/ambiguous states and do not become zero jobs or zero activity.

The crawl found one previously accepted exact company website, matching the M04 count of one. The benchmark emitted no M05 job or activity claims and found no additional company with hiring/activity data. Its employer/event-pair claim sample is therefore **zero**; the report gives no precision estimate or population-level conclusion. There were zero wrong-company M05 publications and zero missing evidence/proof errors because there were no M05 published claims. The deterministic synthetic tests exercise those publication paths and adversarial cases.

The active source policy names only exact-company-owned websites, with transient factual extraction and a rule to skip sources if their terms prohibit the use. No ATS origin or external activity provider is enabled. Site-specific website terms remain unreviewed where no source-specific terms decision was available; the benchmark records this instead of assigning the website a licence. All publication gates pass for the claims actually emitted. Since no M05 claim was emitted, those checks do not establish a precision or rights result for a broader source population. Search, paid APIs and model dependencies remain disabled.
