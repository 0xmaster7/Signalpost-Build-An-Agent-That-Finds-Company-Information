# M08 synthesis and research UX

## Canonical boundary

The server-rendered application reads the canonical evaluator envelopes produced by the existing pipeline. It does not fetch company data, modify checkpoints, or publish alternate facts. Claims keep their organization number, public state, period and scope dimensions, evidence IDs, and source snapshots. Evidence must bind to a same-company snapshot with a matching source URL and content hash; frozen registry rows retain their row hash while pointing to the aggregate snapshot hash. The UI links to those evidence records and shows source dates and hashes.

The canonical M07 changes are read as recorded events. Summaries use fixed deterministic sentence templates and are validated against claim and event evidence. A change event is described as an observed event. Its effective date is stated only when the event supplies one. Unavailable, blocked, ambiguous, and otherwise unknown sections remain visible as states.

## FIND, COMPARE, VERIFY

FIND uses a deterministic local index over the loaded canonical envelopes. Text matching is limited to exact organization numbers, company names, and a fixed set of field aliases. Structured filters combine with AND. A known value can match only when the canonical claim is available and its dimensions agree; unknown records are returned separately. Financial predicates require exact currency, period end, and scope. No conversions, rankings, or inferred values are produced.

COMPARE accepts two to four exact organization numbers. Financial facts are comparable only when period, currency, scope, and unit agree and there is one unambiguous current value per company. Corrections, missing dimensions, and missing values remain visible and prevent comparison. There is no ranking or cross-company attribution of citations.

VERIFY returns supported, contradicted, insufficient-evidence, or unavailable with citations from the requested company's own claim set. It requires all dimensions for financial propositions and does not treat a failed lookup as zero or absence.

## HTTP and output safety

FastAPI serves server-rendered HTML. Dynamic text is HTML-escaped, outbound evidence links accept only HTTP and HTTPS, and links use `noopener noreferrer`. The UX is read-only and makes no production outbound requests. Routes validate organization numbers, comparison cardinality, filter fields, operators, and query lengths. Desktop and narrow-screen layouts support keyboard focus and native form controls.

## Model and search state

No model key or reproducible model adapter is available, so synthesis uses deterministic fallback templates. This is a supported M08 mode. External search remains disabled and is not part of FIND; FIND queries only the current canonical local dataset. No paid API or model dependency was added.

## Evaluation

`tests/fixtures/m08/canonical.jsonl` and `research-gold.json` form an independent, deterministic four-company corpus. The M08 evaluator checks exact FIND membership and unknown sets, COMPARE states and citation ownership, VERIFY outcomes and citation ownership, unsupported-question abstention, synthesis support, and citation completeness. It also reports measured query latency on that corpus. The checked-in CI runs the evaluator and focused adversarial tests.
