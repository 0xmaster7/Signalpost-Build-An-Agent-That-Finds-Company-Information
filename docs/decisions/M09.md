# M09 RC1 decisions and evidence boundaries

M09 does not enable a new source, search provider, model, paid API, or external credential. The live RC1 smoke is limited to the existing 100-company fixture, the documented BRREG APIs, and the bounded exact-company website phase through the M01 network gateway. Robots policy remains unchanged: ordinary website robots transport/server failure is fail closed and distinct from disallow; explicit disallow blocks; the audited narrow BRREG structured-API exception remains confined to exact official API paths.

The official first-submission score remains evaluator-owned. The current public diagnostic arithmetic is 26.92 evidence + 12 synthesis + 8 UX = 46.92; qualification at 65 therefore needs 18.08/50 recall under that mix. It is not a locally calibrated prediction. No local percentage is converted into a Builderr score.

The scale runner now supplies distinct checksum-valid synthetic organisation numbers and an exact local registry row for each offline input row. That measures parser/runner/checkpoint/writer behavior, not factual coverage. Scheduler simulations keep actual network requests at zero and identity safety marked not measured. The 25%, 50%, and 90% crash gates kill the real CLI process after durable envelope writes and compare the resumed semantic output to an uninterrupted run.

The tldextract dependency now uses its pinned packaged Public Suffix List snapshot with caching and URL fetches disabled. Domain identity decisions no longer depend on a developer home-directory cache or network access. The same fix is applied to the retained starter website helper.

Unresolved Builderr inputs remain in [`builderr-questions.md`](../builderr-questions.md) and [`contract-matrix.md`](../contract-matrix.md). Runtime fallbacks remain 1,800 seconds hard, 1,350 seconds soft, 300 seconds completion reserve, `12 * N + 1,000` physical requests, zero paid cost, one envelope per input row, JSONL output, and the documented conservative cutoff. No unknown evaluator field name or official limit is treated as satisfied.

RC1 quality reporting separates four-company independent gold regression, deterministic adversarial fixtures, descriptive live observations, and offline/simulated resource measures. These do not estimate population precision or the official score. The external coverage comparison must remain a measured comparison to the M00 starter/registry baseline; unknown or zero-claim output is not counted as recall.
